# Portfólio · Leandro Teodoro

> "Conectar ideias que parecem distantes é onde as melhores soluções aparecem."

Portfólio pessoal de Leandro Teodoro, futuro Engenheiro de IA e membro da **LOT**, uma equipe bootstrapping. Mostra a profissão dos sonhos, os conhecimentos atuais, a stack, a jornada e os projetos da LOT (Flow Enterprise, IESP e STMJ), além dos contatos.

## Como rodar

É um site estático de uma página. Abra `index.html` no navegador, ou sirva a pasta:

```bash
python3 -m http.server 8000
```

e acesse http://localhost:8000.

## Publicação

Pode ser publicado de graça na Vercel (importe o repositório, sem configuração de build) ou no GitHub Pages (Settings → Pages → branch `main`, pasta raiz).

## Visual

Fundo preto com grade sutil, tons de cinza e branco com detalhes dourados, tipografia Bricolage Grotesque, Manrope e JetBrains Mono, e animações leves que respeitam a preferência de movimento reduzido do sistema.
